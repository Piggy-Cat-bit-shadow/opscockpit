## What OpsCockpit reuses from Homelable

OpsCockpit is *not* a fork. It is a new, lightweight project that borrows the
frontend topology wheel. Reused, adapted pieces:

### Frontend (adapted, not copied verbatim)

- **React Flow integration** — `@xyflow/react` (`<ReactFlow>`, `Controls`,
  `Background`, `Panel`, `applyNodeChanges`/`applyEdgeChanges`), node types
  registry, edge types.
- **Dagre auto-layout** — `applyDagreLayout` approach for top-to-bottom
  hierarchical layout (`utils/layout.ts` pattern), port-ordered child
  placement.
- **BaseNode pattern** — the `BaseNode` component style (icon tile + label +
  status dot + side handles) was the inspiration for OpsCockpit's
  `PortNode`/`ProtocolNode`/`ServiceNode` renders.
- **UI primitives** — the `shadcn`-style `ui/` component patterns (button,
  tooltip, dialog, badge, separator) informed OpsCockpit's minimal UI kit.
- **Zustand store pattern** — single `create` store for canvas/UI state.
- **Type model shapes** — `NodeData`/`EdgeData`/`ServiceStatus` naming and
  structure informed the OpsCockpit data model.
- **Fonts & theme ideas** — dark, restrained, status-color vocabulary.

### Not reused

Nothing from the Python backend is used. Nothing from the following
Homelable features is carried over: FastAPI/SQLAlchemy/SQLite, network
scanner / nmap UI, Zigbee, Z-Wave, Proxmox, MCP, floor plan, inventory,
multi-board, public view, Home Assistant, topology editing, manual node
add/delete, node resizing, notes, group editor, PNG/SVG export, theme editor.

## What OpsCockpit changed

- All Python/FastAPI backend code replaced by a single Go binary
  (`opscockpit`) with a tiny `net/http` API and no database.
- Topology is **data-driven runtime state** (`state.json`) generated by
  collectors — the frontend knows no service names, ports, or units.
- Node set reduced to `port` / `protocol` / `service` (plus an `internet`
  root). Layout is computed from a deterministic port tree, not a canvas the
  user edits.
- Polling replaces Homelable's WebSocket status channel.
- Added the mobile collapsible port tree and bottom-sheet detail view.
- New visual language: restrained dark grey, minimal chrome.
